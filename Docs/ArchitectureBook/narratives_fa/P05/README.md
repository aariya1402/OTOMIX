# فاز ۵ - پایلین دستیابی و تحلیل ویژه‌ها

**وضعیت:** ۵/۲۲ تکمیل شده، ۳ مسدود شده.

فاز ۵، آدیپتور API مختصر (نرمالیزاسیون ۴۴.۱ کیلوزیکل، سیم‌سکم/سیم‌ویر کنترات، نظم حافظه WASM، پاسخ به خطا یا مدت زمان محدود)، نسخه ۱.۲ کنترلی فیچر (بیمپ، انرژی، خواص میکس، نقشه صوتی، انتقال، نقض حافظه، دروازه کاملوت)، و پایلین متناسبی که نتایج را به صورت تراکنشی در حالت محدودیت تیانت نگه می‌دارد، را ارائه داد. چندین وظیفه تصمیم‌گیری مالک (OQ-۲۰/۲۱/۲۲) و وظایف وابسته به تورسیو تا دیگری هنوز TODO یا DEFERRED است.

## چه چیزی ارائه شد

- **P05-T01-S01-M01** - اجرای نرمالیزاسیون ورودی (AudioBuffer) به ۴۴.۱ کیلوزیکل و کاهش آن به یک آرایه فلیت ۳۲.
- **P05-T01-S02-M01** - پیوند ورودی/خروجی آدیپتور به سیم‌سکم دیرکت ۷ و اجرا شدن سیم‌ویر در زمان ترکیب JSON موتور به کنترلی فیچر.
- **P05-T01-S03-M01** - بسته‌بندی هر استخراج در try/finally که فراخوانی releaseResult را انجام می‌دهد.
- **P05-T01-S03-M02** - اضافه کردن یک بررسی عملکرد حافظه قبل و بعد و یک آزمون بازگشتی برای احتمال افتادن حافظه در استخراج‌های تکراری.
- **P05-T01-S03-M03** - در صورت خطا در کارگر یا مدت زمان محدودی بیش از ۵۰۰۰ میلی‌سیکوند، بار را از طریق نوودهای تحلیل RMS ویژه‌های ویژه و بازگشت یک مجموعه اولیه ویژه بدون توقف صف انجام می‌دهد.
