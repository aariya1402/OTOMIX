# فاز 8 - MixPlan، ویژه‌ی کاربری و ساختار Redux

**وضعیت:** 0/18 تکمیل شده، 2 مسدود.

فاز 8 هنوز شروع نشده است. این فاز کاتالوگ انتهایی و کلاینت React/Redux را ساخته است: بیلی‌بندی متناسب و صف مرتب، دو ستون انتخاب با نمایش موقت و حالت خالی، هشدار مربوط به گروه آغازین، تولیدکننده MixPlan (توصیه‌های وزنی، راه حل‌های مساوی، تأخیرهای محدود با نمودار صوتی، و فراخوانی PlanTransition)، پوشش‌های نمودار صوتی برای مناطق صوتی و تأخیر قبل از شروع، و نمایش پیش‌بینی میکس که با مراقبت اجرایی از طریق پورت DSP متصل است. قبل از شروع هر کاری در زمینه ویژه‌ی کاربری، GAP-020 نیاز دارد تا ماتریس وصله‌ی ویژه‌ی کاربری (عنصر ویژه‌ی کاربری → قطعه Redux → مقدار کاتالوگ → مقدار ثبت ویژه) را تهیه کند.
