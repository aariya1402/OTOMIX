# فاز 9 - XML ​​Export & Set Shop

## آنچه P09 ارائه می دهد

P09 یک «MixPlan» تکمیل شده را به **مصنوعات قابل حمل و قابل پخش** و یک لیست بازار تبدیل می کند.

| صادر کننده | Format | Target |
|----------|--------|--------|
| **سراتو** | `.crate` + XML | Serato DJ Pro / Lite |
| **تراکتور** | `.nml` (XML) | Native Instruments Traktor |
| **Rekordbox** | `.xml` + `.pdb` | Pioneer Rekordbox |
| **جهانی** | `.json` (OTOMIX native) | Re-import, archival |

**رمزگذاری**: AES-256-GCM در هر بار دانلود، کلید مشتق شده از رمز خرید (P09-T03).
**بایگانی**: `.zip` با مانیفست (SHA-256 از هر ساقه)، با امضای کلید OTOMIX ED25519.
**Marketplace**: فراداده فهرست (عنوان، توضیحات، ژانر، محدوده BPM، کلید، مدت زمان، کلیپ پیش نمایش)، ردیف قیمت، تقسیم درآمد.

**ورودی**: `MixPlan` + ساقه های رندر شده (از زنجیره صادرات P04) + فراداده کاربر.
**خروجی**: URL دانلود امضا شده + رکورد خرید (به حسابرسی P06/P10).

**کارهای مسدود شده (2)**:
- OQ-12: Rekordbox ".pdb" فرمت باینری کامل مهندسی معکوس.
- OQ-13: قرارداد هوشمند تقسیم درآمد بازار در مقابل دفتر کل خارج از زنجیره.
