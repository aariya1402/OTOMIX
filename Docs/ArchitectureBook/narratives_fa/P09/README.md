# فاز 9 - خروجی XML و ایجاد فروشگاه

**وضعیت:** 0/20 تکمیل شده، 3 مسدود شده.

فاز 9 هنوز شروع نشده است. این فاز مجموعه‌های پیکربندی را حفظ می‌کند، مetadata XML مرحله‌ای برای نرم‌افزارهای DJ مانند Rekordbox، Traktor، VirtualDJ و Serato را از Attack Grid تولید می‌کند، مانیتورینگ فروشگاه (فروشگاه خرید) را به صورت محاکی (متناسب با تأمین کننده)، ورودی‌های وب معتبر، مجوزهای تراکنشی، تولید مجموعه‌های متناظر (idempotent)، دانلودهای موقت با تأیید و محدودیت، و مانیتورینگ بدون از دست دادن (lossless gating) اجرا می‌کند، صفحه‌های اصلی تولیدکنندگان با نمایش امن، و فرآیند دو مرحله‌ای برای حذف محتوا. چهار وظیفه مسدود شده است به دلیل تصمیم مالکان (OQ-10، OQ-12، OQ-13).
